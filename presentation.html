HALL 05 — CORE INNOVATION

ระบบกราฟความรู้: Data Booming vs Interactive

หัวใจเทคโนโลยีหลักของ GRURU MUSEUM ที่ส่งมอบประสบการณ์การค้นพบความรู้ 2 รูปแบบ

01. DATA BOOMING

Guided Discovery

ประสบการณ์แบบนำทาง เริ่มจากจุดประกาย 1 หัวข้อ แล้วเกิดการ “ระเบิด” เป็นโหนดลูกเชื่อมโยงทีละระดับ

Burst Effect: แตกออกเป็น 6–12 โหนดลูกในแบบวงรัศมีทีละ 40ms
Interactive Depth: ผู้ใช้กดสำรวจเจาะลึกลงไปได้สูงสุด 3 ชั้นต่อเนื่อง
Seamless Bridge: ส่งต่อไปยัง Interactive Graph แบบเต็มอัตโนมัติ

02. INTERACTIVE GRAPH

Free Exploration

แผนที่เครือข่ายความรู้ฉบับเต็มด้วย D3 Force-Directed Simulation ให้ผู้ใช้ กรอง ค้นหา และหมุนดูได้อิสระ

Dynamic Sizing: ขนาดโหนด 8–32px แปรผันตามจำนวนความเชื่อมโยง
Semantic Relations: แบ่งประเภทเส้น influenced / derived_from / used_in
Explorer Tools: แถบเลื่อนเวลา Time Slider, หมวดหมู่ และ Minimap

HALL 08 — MOTION SYSTEM

Motion Choreography: Scan → Decode → Connect

ระบบแอนิเมชันที่สะท้อนการทำงานของห้องแล็บวิทยาศาสตร์อย่างแม่นยำ ไม่รบกวนสายตา

PHASE 01

SCAN

เนื้อหาปรากฏขึ้นตามเส้นสแกนแนวนอนที่กวาดผ่านหน้าจออย่างนุ่มนวล

Duration: 300ms
PHASE 02

DECODE

หัวข้อและตัวเลขมีการสลับตัวอักษรแบบ Matrix Decode ราว 600ms ก่อนหยุดนิ่ง

Duration: ~600ms
PHASE 03

CONNECT

เส้นกราฟความรู้ค่อย ๆ ลากเชื่อมโยงระหว่างโหนด พร้อมแสงเรืองวงแหวน Lime Pulse

Easing: cubic-bezier(0.16, 1, 0.3, 1)

มาตรฐานความเร็ว (Timing Standard)

  • 150ms : Micro-interactions เช่น ปุ่มโฮเวอร์ แสงปฏิกิริยา
  • 300ms : UI Navigation, Slide Card Transition
  • 600–1000ms : Narrative Scenes และ Data Booming Expansion

WCAG Accessibility Rules

รองรับ prefers-reduced-motion โดยปิดกลิตช์และสลับตัวอักษรเหลือเพียง Fade ปกติ และ ห้ามแสงกะพริบเกิน 3 ครั้ง/วินาที อย่างเด็ดขาด
